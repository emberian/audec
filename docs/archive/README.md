# Archived campaign documents

Design notes, swarm plans, cycle ledgers, and agent handoffs written during
the 2026 build-out. They record how the tree got here and are kept for that
reason; several describe intentions the tree never met or has since changed.
None of them is normative. Start from `../STATE.md`; the normative designs
that still bind the code are `../LANGUAGES.md`, `../COMMAND_ENVELOPE.md`,
`../RENDER_TILES.md`, `../COVERAGE.md`, and `../READINGS.md`.
