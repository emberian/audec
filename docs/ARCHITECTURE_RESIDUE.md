## The five that change the most

1. **One reveal identity.** `ObjectRef` is the only durable identity; `RevealRequest{object, hint}` the only ask; `RevealReceipt{resolution, guard, disposition}` the only answer. Surfaces implement `locate(ObjectRef)` and own no target enum. The two `EditorTarget`s merge into the typed one; the raw-u64 one becomes a serde DTO. A refusal reason then survives crossing a surface, which is what `reverse_navigation` was written for.
2. **One workbench event channel.** One `enum WorkbenchEvent` (the ten `Pending*` structs as variants), one sender handed to every view factory, one drain in the ticker; `prepare_for_document_install` drops the receiver instead of resetting fourteen fields. This is the teardown bug class `pane_cohesion` was written for.
3. **One freshness guard.** `Fresh<T>{epoch, value}` with one `Epoch` per authority (document, project, selection, analysis); a mismatch is a named diagnostic, not a silent drop.
4. **Delete the compatibility half of `control_views`.** Views hold a read-only graph snapshot plus a `ControlActionCallback`; no `Box<dyn Backend>`, no local undo, no mode enum. The one `Compatibility` caller wants an editor with no lanes, which is an empty graph.
5. **Delete unfalsifiable migrations, keep the loud failure.** One constant per format, one `!= CURRENT → Err(UnsupportedSchema)`, zero transform branches until an old file exists. `project_codecs.rs:281`'s assets 1-or-2 gate is decorative; compatibility rests on `#[serde(default)]`; make that explicit or drop the gate.
